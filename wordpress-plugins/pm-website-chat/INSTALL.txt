PM Website Chat — install / update

Upload this file
----------------
  exports/pm-website-chat-VERSION/pm-website-chat-VERSION.zip
  (same layout as 1.0.10 — e.g. exports/pm-website-chat-1.0.24/pm-website-chat-1.0.24.zip)

Inside the zip (one folder):

  pm-website-chat/
    pm-website-chat.php
    assets/
    includes/
    …

That inner folder name must stay pm-website-chat so WordPress updates the same
plugin. A flat zip (files at the root) makes WP create a second plugin from the
zip filename.

If you already have two entries under Plugins:
1. Keep wp-content/plugins/pm-website-chat/
2. Delete the other (e.g. pm-website-chat-1.0.x)
3. Upload the versioned zip again → Replace current with uploaded

Option A — Upload plugin
------------------------
1. Plugins → Add New → Upload Plugin
2. Choose the zip from exports/pm-website-chat-VERSION/
3. Replace current with uploaded if prompted, or Install → Activate

Option B — WP File Manager
--------------------------
1. Delete broken/empty pm-website-chat folders under wp-content/plugins/
2. Extract the zip and put the pm-website-chat folder into wp-content/plugins/
3. Activate "PM Website Chat"

After activate: Settings → PM Website Chat
- Hub URL: https://marketing.petersandmay.com
- Site key: same value as Vercel env CHAT_SITE_KEY (server-side only; not shown in page JS)
- Enable widget

Staging (https://stg-petersmay-staging.kinsta.cloud/)
- Install/activate on staging WordPress, not production www.
- Widget calls same-origin /wp-json/pm-website-chat/v1/hub/... (proxy.php).
- Hub URL and site key are still required in Settings (server-side only).
