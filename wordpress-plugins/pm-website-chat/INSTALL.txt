PM Website Chat — install / update

IMPORTANT — avoid a "new plugin" duplicate
------------------------------------------
The zip MUST contain a single top folder named exactly:

  pm-website-chat/
    pm-website-chat.php
    assets/
    includes/
    …

Do NOT upload a flat zip (files at the root). WordPress then creates a
folder from the zip filename (e.g. pm-website-chat-1.0.18) and you get
a second plugin.

If you already have two entries under Plugins:
1. Keep the one in folder wp-content/plugins/pm-website-chat/
2. Delete the other (e.g. pm-website-chat-1.0.x)
3. Upload the correct zip again (Updates the same plugin)

Option A — Upload plugin (preferred)
------------------------------------
1. Plugins → Add New → Upload Plugin
2. Choose: exports/pm-website-chat-1.0.18/pm-website-chat-1.0.18.zip
   (or pm-website-chat.zip in the same folder — identical contents)
3. Click Replace current with uploaded if prompted, or Install → Activate

Option B — WP File Manager
--------------------------
1. Delete broken/empty pm-website-chat folders under wp-content/plugins/
2. Upload the pm-website-chat folder from the zip into wp-content/plugins/
3. Activate "PM Website Chat"

After activate: Settings → PM Website Chat
- Hub URL: https://marketing.petersandmay.com
- Site key: same value as Vercel env CHAT_SITE_KEY (server-side only; not shown in page JS)
- Enable widget

Staging (https://stg-petersmay-staging.kinsta.cloud/)
- Install/activate on staging WordPress, not production www.
- Widget calls same-origin /wp-json/pm-website-chat/v1/hub/... (proxy.php).
- Hub URL and site key are still required in Settings (server-side only).
